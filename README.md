# Gonzales Bodega — Menu

A simple, minimal menu prototype: kitchen food plus everyday deli items. Customers add items to an order and send it to the store on WhatsApp.

- Edit the store name, WhatsApp number, address and menu items at the top of the `<script>` in `index.html`.
- Product images live in `images/` and are named after each item's `id`.
- Product photos are manufacturer pack shots, used as placeholders for this prototype.
